# Brew & Bloom Cafe: Landing Page

A responsive, single-page website for a fictional cafe. Built with plain HTML, CSS and JavaScript (no frameworks) as a demo of the kind of simple business site I can build for local shops.

## Features
- Fully responsive layout (phone, tablet, desktop)
- Mobile hamburger navigation
- Menu with category filter (All / Coffee / Bakery / Cold drinks)
- Table booking form with JavaScript validation (name, email, guests, date)
- Smooth scrolling, accessible labels, semantic HTML

## Run it
No install needed. Open `index.html` in any browser.

## Project structure
```
cafe-landing-page/
├── index.html
├── style.css
├── script.js
└── README.md
```

## Concepts used
Semantic HTML, CSS variables, Flexbox and Grid, media queries, DOM manipulation, event handling, form validation.

> Note: Brew & Bloom is a made-up business. The form does not send data anywhere.
